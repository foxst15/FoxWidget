# 🦊 FoxWidget v3.0 — Liquid Glass Ultra Edition

Phiên bản **FoxWidget v3.0** tập trung hoàn thiện hiệu ứng **Kính Lỏng Quang Học 3D (Optical Liquid Glass)** thay thế hoàn toàn phong cách khối đặc nhàm chán:
- **Bộ dựng kính lỏng 5 lớp (`LiquidGlassRenderer`)**: Tán sắc viền cầu vồng (Cyan / Magenta), tụ quang lòng kính, vòm phản quang giọt nước và viền cắt kim cương 1px.
- **5 sắc thái kính lỏng**: *Hắc Diện Titan (Obsidian)*, *Lưu Ly Tím (Amethyst)*, *Băng Tinh Xanh (Glacier)*, *Ngọc Lục Bảo (Emerald)*, và *Cực Quang Bạc (Prismatic)*.
- **Thanh chỉnh quang học realtime**: Tùy chỉnh độ đặc khối kính, cường độ tán sắc viền và độ bóng bề mặt trực tiếp trên màn hình xem trước 1:1.
- **Tương thích Android 16/17 & mọi ROM hãng**: HyperOS 3, One UI 8.5, ColorOS 17, OriginOS 6, MagicOS 10.
